## Troubleshooting Approach

When troubleshooting technical issues, I follow a structured process:

1. Identify the reported issue
2. Verify the symptoms
3. Check basic settings and connectivity
4. Review hardware and device status
5. Review drivers and system services
6. Isolate possible causes
7. Test corrective actions
8. Verify the outcome
9. Document the troubleshooting process
